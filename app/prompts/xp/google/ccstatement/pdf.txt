date = DD/MM/YYYY → DD-MM-YYYY
description = transaction description
installments = installment info if present (e.g. [01/12]), empty string otherwise
amount = negative for purchases/expenses, positive for payments/credits
balance = 0

OUTPUT: Return ONLY valid JSON. Minify.
{
  "transactions": [
    {"date": "DD-MM-YYYY", "description": "text", "installments": "[01/12]", "amount": -123.45, "balance": 0, "category": "Outros"}
  ]
}
Rules: (1) Numbers with dot decimal. (2) DD-MM-YYYY format. (3) No markdown. (4) ONLY the JSON object.
