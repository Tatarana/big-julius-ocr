description = transaction description
amount = positive for credits (entradas), negative for debits (saídas)
balance = running account balance after the transaction

CATEGORIES: RESTAURANTE→Restaurante, MERCADO→Mercado, DROGARIA→Saúde, POSTO→Combustivel, AMAZON/SHOPPIN→Compras, ESTACIONAMENTO→Transporte, LATAM/GOL/HOTEL→Viagem, SEGUROS→Seguros, PIX/TED/DOC/TRANSFERENCIA→Transferência, SALARIO→Salário, default→Outros

OUTPUT: Return ONLY valid JSON. Minify.
{
  "transactions": [
    {"date": "DD-MM-YYYY", "description": "text", "installments": "", "amount": -123.45, "balance": 1000.00, "category": "Outros", "owner": "owner name"}
  ]
}
Rules: (1) Numbers with dot decimal. (2) DD-MM-YYYY format. (3) No markdown. (4) ONLY the JSON object.
