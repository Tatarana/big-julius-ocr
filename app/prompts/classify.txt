OUTPUT: Return ONLY a valid JSON object. Minify.
{"bank": "bank_name", "doc_type": "ccstatement", "owner": "FULL NAME"}

Rules: (1) No markdown. (2) ONLY the JSON object. (3) Use lowercase for bank and doc_type values.
